ZPK Digital ID

Local-first identity registration and recovery for Guatemalan citizens. This downloadable Android app creates a pseudonymous ZPK identity, checks synthetic CUI risk, issues a signed authentication proof, encrypts a local audit receipt, and prepares a redacted recovery packet on device.

Install

Use an Android emulator or connected Android device.

adb install -r kan-debug.apk
adb shell monkey -p gt.kan.kan_app 1

Use synthetic CUI 1234567890101 for the main flow.

  • Offline ZPK identity registration with no cloud dependency.

Important Limits

  • No real personal data or real breach data is included.
  • This is not production legal advice.
  • The APK is default local mode and does not embed a Gemini API key.
  • Cactus tool-calling is not working yet; Cactus local inference is documented separately.
  • ML Kit/AICore on-device Gemma generation requires supported hardware; the Mac emulator evidence shows a fail-closed fallback.
